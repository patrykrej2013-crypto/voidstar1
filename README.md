# VoidStar - etap 1 (szkielet, menu, config, motywy)

Wymagania: Java 21, Gradle 8.x (albo gradle wrapper z szablonu Fabric).

Budowanie:
    gradle build
Gotowy mod: build/libs/voidstar-0.1.0.jar -> wrzucic do mods/ razem z Fabric API 0.115.0+1.21.1

Uruchomienie z IDE: gradle runClient

Klawisz V = menu. Przycisk "VoidStar" jest tez w menu glownym (lewy gorny rog).
Config: config/voidstar_config.json

Bez instalowania czegokolwiek: wrzuc caly folder na GitHub (darmowe konto), zakladka
Actions -> build -> po kilku minutach pobierz "voidstar-jar" (w srodku gotowy .jar).
